# Smart Library Management System

## About the Project
Smart Library Management System is a Java-based console application developed using Object-Oriented Programming (OOP) concepts. It helps manage library books by providing features to add, view, search, issue, and return books.

## Features
- Add new books
- View all available books
- Search books using Book ID
- Issue books
- Return books
- Prevent duplicate Book IDs
- Track book availability status

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Encapsulation
- Constructors
- ArrayList
- Scanner
- Eclipse IDE

## Project Structure
- `LibraryBook.java` – Stores book details and manages book information.
- `LibraryApp.java` – Contains the main program and library management operations.

## How to Run
1. Download or clone this repository.
2. Open the project in Eclipse IDE.
3. Run `LibraryApp.java` as a Java Application.
4. Select an option from the console menu.
5. Enter the required book details.
